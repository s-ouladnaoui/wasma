# wasma
Weighted Automata Sequence Mining Algorithm. This project is the extension of the pattern mining formal series-based approach to sequential patterns. Based on an improved version of the well-known subset construction method: Two variants are implemented that rely or not on the state existence check clause.  
  WASMA-wsc: with state existence check, and 
  WASMA-ssc: sans state existence check  
This work has been published in Information Sciences Journal link: https://www.sciencedirect.com/science/article/abs/pii/S0020025525004803
